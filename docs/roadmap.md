# ACU Life Development Roadmap

## Phase 0 — Pre-production
- [ ] Confirm the game engine and target platform.
- [ ] Create a list of campus landmarks for the first playable area.
- [ ] Sketch a simple top-down map.
- [ ] Estimate distances and choose a consistent in-game scale.
- [ ] Decide the visual style.

## Phase 1 — Movement prototype
- [ ] Create a Unity 3D project.
- [ ] Add a third-person player controller.
- [ ] Add camera follow and collision.
- [ ] Build a greybox test area using cubes and planes.
- [ ] Test walking speed, turning, slopes, and stairs.

## Phase 2 — First campus block
- [ ] Add a few recognizable buildings as simple blockout models.
- [ ] Add roads, footpaths, grass, and basic lighting.
- [ ] Add collision to buildings and environment.
- [ ] Add a simple map or landmark labels.

## Phase 3 — Campus life
- [ ] Add fictional NPCs.
- [ ] Add interaction prompts and dialogue.
- [ ] Add one simple mission or activity.
- [ ] Add a basic time-of-day system if performance allows.

## Phase 4 — Polish and expansion
- [ ] Improve models, textures, audio, and animations.
- [ ] Add save/load.
- [ ] Profile performance on target hardware.
- [ ] Expand the playable area only after the first area is stable.

## First milestone definition of done

A player can launch the game, walk around one small campus area, enter a clearly marked interaction range, speak to one NPC, and complete one simple objective.
